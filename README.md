# The World in One Day — 25 November 2026

Entry for the make.fun bounty **news-image-20261125**: one newspaper front
page summing up Wednesday 25 November 2026 in a single image — 50 stories,
every one first reported that day. `main.py` (stdlib only) copies the
pre-rendered `entry.png` to the output directory; `draw_news.py` is the
Pillow script that drew it.
