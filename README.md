A one-page newspaper front page summing up Wednesday 25 November 2026's world news in a single image: 50 stories across 7 regions, every one first reported that day. `main.py` (Python 3.13, standard library only) copies the pre-rendered `entry.png` to the output directory; `draw_news.py` is the Pillow script that drew it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
